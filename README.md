# MC 自动陪玩 AI 智能体（MVP）

这是一个面向 **Minecraft Java 版局域网服务器** 的陪玩智能体。孩子在电脑旁通过语音说话，机器人会在游戏内以文字回应，并完成跟随、资源带路、怪物保护和模板建造。

## 启动

1. 安装 Node.js 20+。
2. 执行 `npm install`。
3. 将 `.env.example` 复制为 `.env`，至少填写 `MC_HOST`、`MC_COMPANION_PLAYER` 和机器人名称。
4. 执行 `npm run dev`。
5. 用 Chrome 或 Edge 打开 `http://127.0.0.1:8787`，允许麦克风后点击“开始说话”。

若服务器启用了正版验证，请将机器人账号认证方式按 Mineflayer 文档配置；不要把账号密码或访问令牌写进仓库。

## 使用方式

| 指令 | 效果 |
| --- | --- |
| 语音或 `!陪玩 跟着我` | 持续跟随孩子 |
| `带我找木头/石头/煤/铁` | 在 64 格内发现资源后带孩子前往；不自动大量代采 |
| `保护我` | 留意附近怪物，优先撤离；非苦力怕且安全时才攻击 |
| `盖小木屋/围栏农场/篝火营地` | 在机器人旁边的空地放置模板所需方块 |
| `停下` | 立即停止寻路与保护循环 |
| `状态` | 报告生命、饥饿和附近威胁 |

`MC_COMPANION_PLAYER` 是语音控制的目标玩家；`MC_ALLOWED_PLAYERS` 可限制游戏内聊天指令的发令人。建议始终填写它们。

## 模型与决策

大模型通过任意 OpenAI 兼容接口配置，负责理解自然语言、选择技能和生成简短回应；未配置时，程序只识别基础口令。Jev 是最终的实时动作闸：它只能从受限技能中选择动作，低置信度、超时或格式异常时会澄清而不是执行。

建造不会破坏现有方块，且只消耗机器人背包中的材料。语音页不保存录音或转写内容；浏览器自身的语音识别服务可能有独立的数据处理规则。

建议先在本地或私有测试服验证。公共服务器往往禁止自动化账号，接入前请确认服务器规则。
