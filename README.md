# MC 自动陪玩 AI 智能体（MVP）

这是一个面向 **Minecraft Java 版** 的陪玩机器人起点：它能进服、聊天、跟随指定玩家、走到玩家身边、停止行动和汇报状态。底层采用 Mineflayer，因此后续可接入采集、战斗、建造和大模型任务规划。

## 启动

1. 安装 Node.js 20+。
2. 执行 `npm install`。
3. 将 `.env.example` 复制为 `.env`，填写服务器地址和机器人名称。
4. 执行 `npm run dev`。

若服务器启用了正版验证，请将机器人账号认证方式按 Mineflayer 文档配置；不要把账号密码或访问令牌写进仓库。

## 游戏内指令

| 指令 | 效果 |
| --- | --- |
| `!陪玩 help` | 查看帮助 |
| `!陪玩 follow` | 持续跟随发令玩家 |
| `!陪玩 come` | 走到发令玩家身边 |
| `!陪玩 stop` | 停止寻路与移动 |
| `!陪玩 status` | 报告生命、饥饿和坐标 |

`MC_ALLOWED_PLAYERS` 可限制仅响应指定玩家，建议在公共服务器始终设置它。

## 下一步：从机器人到 AI 陪玩

1. **感知层**：把附近实体、背包、生命、时间和玩家聊天压缩成状态摘要。
2. **规划层**：让 LLM 只输出结构化意图，例如 `follow`、`gather`、`build`；再由本地策略校验。
3. **执行层**：实现采集、合成、战斗、放置方块等受限技能。
4. **安全层**：玩家白名单、指令限流、危险方块/破坏操作白名单、紧急 `stop`，以及所有行为日志。

建议先在本地或私有测试服验证。公共服务器往往禁止自动化账号，接入前请确认服务器规则。
