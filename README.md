# MC 自动陪玩 AI 智能体

面向 **Minecraft Java 版局域网** 的陪玩机器人。进服后会自己待在孩子身边；语音或聊天给出任务后，它会把长任务拆成步骤并持续做完，而不是只动一下就停。

## 启动

1. 安装 Node.js 20+。
2. 执行 `npm install`。
3. 将 `.env.example` 复制为 `.env`，至少填写 `MC_HOST`、`MC_COMPANION_PLAYER` 和机器人名称。
4. 执行 `npm run dev`。
5. 用 Chrome 或 Edge 打开 `http://127.0.0.1:8787`，允许麦克风后点击“开始说话”，也可以打字。回复会同步朗读。

掉线或被踢出后会自动重连，间隔从 3 秒逐渐增加到 30 秒。重新进入后会说「我回来了」。没做完的任务需要再说一次。按 Ctrl+C 退出后不再重连。

若服务器启用了正版验证，请按 Mineflayer 文档配置机器人账号；不要把账号密码或访问令牌写进仓库。

## 它会自己做的事

- 没有任务时会跟着孩子。你在挖方块时，它会挖旁边同一种，不抢你正在挖的那一块。
- 怪物靠近你时，它会停下手头的事过来一起打；苦力怕仍然先撤。
- 白天你在附近闲着时，它会自己去旁边捡一点花或木头，然后回来。
- 天黑了会挨着你；背包里有火把时，会在身边插一支。你说「睡觉」或「跳过夜晚」时，它会去附近的床上躺下。你也上床，夜晚才会过去。天亮后它会起来回到你身边。
- 饿了会自己吃东西（背包里要有食物）。
- 长任务按步骤推进：例如“去砍树盖房子”会先采集木头，再回到身边，再盖小木屋。
- 做完或超时（约 5 分钟）会回到孩子身边说明情况。
- 孩子走远时会先跟上，而不是把人丢在原地。

## 可以怎么说

不限于固定口令。例如：

- `跟着我` / `坐下陪我` / `睡觉` / `跳过夜晚` / `攻击` / `去打僵尸` / `停下` / `保护我` / `状态`
- `去砍一些木头，砍完回来`
- `帮我盖小木屋`
- `摘点花` / `把苹果给我` / `去打附近的僵尸`

`MC_COMPANION_PLAYER` 是语音控制的目标玩家；`MC_ALLOWED_PLAYERS` 可限制游戏内 `!陪玩` 指令的发令人。

游戏内聊天仍可用：`!陪玩 去砍树盖房子`。

## 模型与决策

代码先列出此刻能做的动作，Jev 只选择 `a0`、`a1` 这样的编号，不能自己发明技能名。危险时不询问模型，直接保护或撤离。

长任务由大模型给出步骤。第一次会等规划完成再回复孩子；之后规划在后台更新，不会卡住游戏里的动作。同一阶段被新指令打断时，旧计划作废。连续失败、没有可做的动作，或大约两分钟，会重新规划。

失败的动作会冷却几秒，最近五次动作和结果会交给下一次选择。模型没返回可执行步骤时，才退回本地口令。

建造仍不覆盖已有方块。不攻击玩家或村民。苦力怕先撤。语音页不保存录音或转写。

建议先在本地或私有测试服验证。公共服务器往往禁止自动化账号。
